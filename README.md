# SWYNEX-Modeling-and-Evaluation

## Project Title
Iris Flower Classification using Logistic Regression

## Objective
The objective of this task is to build and evaluate a baseline
machine learning classification model.

## Dataset
The Iris dataset is used for this project. It contains measurements
of iris flowers and three species:
- Setosa
- Versicolor
- Virginica

## Methodology
1. Loaded the Iris dataset.
2. Separated features and target variable.
3. Split the dataset into training and testing sets.
4. Built a Logistic Regression baseline model.
5. Trained the model using the training data.
6. Generated predictions on the test data.
7. Evaluated the model using accuracy, precision, recall and F1-score.
8. Visualized the confusion matrix.
9. Compared actual and predicted labels.


## Model
Logistic Regression

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Limitations
The Iris dataset is small and relatively simple. Therefore, the model's
performance on this dataset may not represent its performance on complex
real-world datasets. The results can also vary depending on the train-test
split.

## Conclusion
A Logistic Regression baseline model was successfully trained and
evaluated for Iris flower classification. The model was tested on
unseen data using multiple evaluation metrics and a confusion matrix.
